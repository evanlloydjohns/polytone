# Minecraft 26.3 Fabric alpha status

This branch is an experimental Fabric-first port from Polytone 26.2. The
`:fabric:build` task succeeds on GitHub Actions with Java 25 and Gradle 9.6.1.
The workflow uploads an installable JAR and its source JAR. Only the file
without `-sources` belongs in Minecraft's `mods` folder.

The first alpha deliberately disables Polytone's custom shader bindings,
post chains, shadow maps, and Iris integration. Iris is marked incompatible
in Fabric metadata. The old LevelRenderer hook was also disabled, so GPU
particle rendering is unavailable. Other features are still experimental.

For manual testing, use a separate Minecraft 26.3 Fabric instance with Fabric
Loader 0.19.5 and Fabric API 0.161.0+26.3. Install the Polytone alpha JAR
without Iris. Begin with no other optional mods, then add Sodium or resource
packs one at a time. Back up worlds before using an alpha build.

The build currently bootstraps the published 26.2 CodecUI and Nautilus Studio
libraries because 26.3 releases are unavailable through the configured Maven
repositories. CodecUI is bundled, while Nautilus Studio is optional. Their
26.3 runtime compatibility is not yet established. A compile success alone
does not prove that all mixins or bundled libraries work at game startup.

The workflow also attempts a client smoke launch and uploads its log. Runtime
validation and manual in-game testing remain necessary before this port can
be considered stable.

Remaining work includes porting shader uniform discovery to Renderpearl,
rewriting shadow rendering for explicit render passes, restoring the changed
LevelRenderer GPU-particle hook, checking Sodium integration, updating
CodecUI and Nautilus Studio, and restoring Iris support.
