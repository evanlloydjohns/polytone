# Minecraft 26.3 port status

This branch is an experimental Fabric-first port from Polytone's 26.2 branch. It does **not** yet produce a validated, playable 26.3 JAR. The [Fabric build workflow](../.github/workflows/fabric-26.3-build.yml) runs on each push and will upload the JAR when the build succeeds.

The first pass updates the Minecraft, Fabric, Sodium, Iris, and toolchain coordinates, makes the build's published 26.2 libraries available with checksum verification, updates access widener targets, migrates moved Renderpearl imports, and adapts several removed vanilla APIs. The published CodecUI and Nautilus Studio libraries used for compilation are still 26.2 binaries; their runtime behavior on 26.3 has not been validated.

The remaining work is primarily in rendering:

- Port custom shader bindings from the removed `GlslCompiler.addToBindGroup` path to 26.3's Renderpearl pipeline compilation and layout model.
- Move render-pass mixins to the 26.3 frontend pass and compiled-pipeline types, then verify OpenGL and Vulkan uniform handling.
- Rewrite shadow rendering around explicit render passes. Minecraft removed the output texture overrides used by the 26.2 implementation.
- Recheck GPU particle rendering, transparent targets, and Sodium integration under the new pipeline API.
- Update or gate optional Iris integration until a compatible 26.3 API is available to the common module.
- Validate bundled CodecUI and optional Nautilus Studio against 26.3, then launch a Fabric client with the assembled JAR before calling it runnable.

The `:fabric:build` task is the current compile gate. A green compile alone is not a runtime validation because mixin targets and bundled 26.2 libraries may still fail at startup.
